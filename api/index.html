DATA API

日本の公的データを、AI がそのまま使える形に

国税庁、協会けんぽ、厚生労働省、内閣府、経済産業省の gBizINFO など、日本の公的機関が公開している表や登録簿を、AI エージェントやソフトウェアが一度の呼び出しで使える API に作り替える。かさねぎは開業前から、こうしたデータ API の群を開発し、提供してきました。いまその群は、かさねぎのすべてを一つにする土台へ統合しています。その間も実物に触れていただけるよう、群の一例として、JP Local Pack の 10 本を登録なしで無料で開いています。外に開いていない企業情報や補助金のデータ API 群も抱え、AI の資源が増えるほど外へ開いていきます。

ACCURACY

公式の表と、1 円単位で合わせる

給与の計算は、近い値で済ませません。公式の表と規則を、そのまま持っています。

  • 源泉所得税国税庁「給与所得の源泉徴収税額表(令和 8 年分)」月額表・甲欄の 1,856 マス(231 の区分 × 扶養 0〜7 人と、最下行)をそのまま持ち、全マスが公式と一致することを試験で確かめています。社会保険料を引いた後の額が 74 万円以上なら、表の注記どおり 9 つの区分の式で求めます。国税庁「月額表の使い方」の設例とも一致します。
  • 健康保険と介護保険協会けんぽの令和 8 年度の料率を 47 都道府県すべて持ち、東京都の保険料額表 50 行と、等級・範囲・保険料を照合しています。円未満は額表の注記どおり 50 銭以下切り捨て・50 銭超切り上げ。40〜64 歳は、健康保険と介護保険を足してから丸めます。
  • 支援金・年金・雇用保険2026 年 4 月分からの子ども・子育て支援金(0.23%)、厚生年金(18.3%)、雇用保険(一般の事業・労働者負担 5/1,000。標準報酬ではなく賃金にかけ、規則どおりに端数を処理)。
  • 消費税1989 年の 3% から、2019 年 10 月の標準 10%・軽減 8% まで、施行日ごとの履歴を持ちます。インボイス制度の開始日(2023 年 10 月 1 日)も判定し、日付は日本時間で決めます。
  • インボイスの登録簿国税庁の公表データの全件と差分から、5,009,701 件を引ける形に整えています。応答には、データがいつ時点のものかを必ず付けます。
  • 国民の祝日内閣府の公表データから、2024〜2027 年の 75 日(国民の祝日・振替休日・国民の休日)。
