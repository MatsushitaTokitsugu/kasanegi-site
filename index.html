01

Impact-Structure Screening — research tooling, in development (no candidate output yet)

Why it matters

Japan has no confirmed impact structure yet — only one probable crater, Oikeyama in Nagano (Sakamoto et al., 2010). This tooling is built to find the first confirmed ones from public surveys alone, with one processing applied to the whole country.

Research tooling for finding undiscovered meteorite impact structures in Japan. It applies the same terrain, gravity and magnetic processing that can be run across all of Japan to known impact structures worldwide, to test whether known structures are picked up without per-site tuning, before the processing is run over Japan's public observations.

Done so far

  • Same red relief image map processing applied to public 1 m-class terrain models of 48 known structures (US 28, Canada 13, Estonia 5, Germany 2), out of a 354-row inventory.
  • At Oikeyama (Nagano, Japan), the in-house processing matched the nationwide Q-chizu rendering within 1 level per RGB channel on the central tile.
  • Quality of Japan-wide public observations pinned down from primary sources, e.g. national aeromagnetic main line spacing 3–4 km; 7 public gravity stations within 10 km of Oikeyama. 262 commits since 2026-09-20.

Built with Claude

  • Claude Code acts as the supervisor: writes the task briefs for ChatGPT Pro and Codex, checks every returned result against primary sources (papers, survey reports, distributor pages), and records the verified premises in git.
  • Claude Code designed the checks that decide what data exist, e.g. confirming that none of 36 Australian structures has a 1 m product in the public ELVIS portal, against a control site where 1 m products do appear.

日本には確認済みの衝突痕がまだ無い——長野の御池山が probable とされているだけ(Sakamoto et al., 2010)。この道具は、公開観測だけから、一つの処理を国土全体に当てて、最初の確認済み衝突痕を見つけるために作っている。

日本の未発見の隕石衝突痕を探す研究用の道具。日本全土に施せる地形・重力・磁気の処理を、世界の既知の衝突痕に同じ形で施し、例ごとの調整なしに既知を拾えるかを確かめてから、日本全土の公開観測に当てる。

これまで

  • 台帳 354 行のうち既知 48 構造の公開 1 m 級地形に、同じ赤色立体地図の処理を施した。
  • 御池山で、自家製の処理が全国 Q 地図の描画と RGB 各 1 段階以内で一致した(中央タイル)。
  • 全国の空中磁気の主測線 3〜4 km、御池山の周り 10 km の公開重力測点 7 点など、日本の観測の質を一次資料で固めた。262 コミット(2026-09-20 から)。

Claude が担った所

  • Claude Code が監督として、依頼文を書き、返ってきた成果を一次資料と照合して検収し、確かめた前提を git に記帳する。
  • 豪州の 36 構造に公開 1 m 製品が無いことを、1 m が出る対照地点と比べて確定する確認の設計と判定を Claude Code が行った。

02

Bilingual Manga Reader — next flagship, in development

Try the demo

Alignment runs entirely in your browser — nothing is uploaded.

A mobile reader for language learners. Open the two language editions of the same manga you already read; the app aligns the pages on your device and lets you look at the other language through a movable lens over the page. Everything stays on the device — no images are stored on our servers. Android first, then iPhone and PC.

Done so far

  • Page-alignment core (Python; feature matching with MAGSAC and geometric verification) written by Claude: on a real volume, 33 page pairs matched with zero mismatches (Oct 5, 2026).
  • Android app shell on a Mihon fork: 134 Kotlin files, 22,000+ lines, with page matching and lens display running on an emulator.
  • PC prototype (Electron) running; HQ at 270 commits since Aug 29, 2026.

Built with Claude

  • Claude Code designed and wrote the alignment core and the page-matching logic that does not assume page order.
  • Claude Code supervises the whole build: specifications, reviews of code from other models, bookkeeping and git.

バイリンガル漫画リーダー — 次の主力・開発中

位置合わせはブラウザの中だけで動き、何も送信しません。

語学学習者のためのスマホのリーダー。自分が読んでいる同じ漫画の 2 言語版を開くと、アプリが端末の中で頁を合わせ、動かせるレンズでもう一方の言語を見られます。画像はサーバに置かず、すべて端末の中だけで扱います。Android を先に、次に iPhone と PC。

これまで

  • 頁合わせの核(Python・特徴点照合+MAGSAC+幾何検証)を Claude が書き、実物の 1 巻で 33 組の頁を誤対応 0 で合わせた(2026-10-05)。
  • Android 版の器(Mihon の fork): Kotlin 134 ファイル・2 万 2 千行超。頁の照合とレンズ表示がエミュレータで動作。
  • PC 版の試作(Electron)が動作。HQ は 2026-08-29 から 270 コミット。

Claude が担った所

  • 頁合わせの核と、頁の順序を仮定しない照合の論理を Claude Code が設計し書いた。
  • 仕様・他のモデルが書いたコードの検収・記帳・git を Claude Code が監督。

03

An experiment in AI-run production — two sports video channels (live; one monetized)

We run two YouTube channels as a live experiment: can a production line built and operated by Claude Code reach real audiences and revenue with a single human reviewer? It did. The line detects a game's end, assembles the facts and fan commentary, writes and narrates, and uploads as private; a person reviews and publishes. The experiment funds the studio, and what we learn about running AI operations feeds the other products.

Two channels: 158 public videos, 1.9M+ lifetime views, about 2,500 subscribers (Oct 2026).

Built with Claude

Claude Code designed the soccer line end to end and wrote the baseball line's rulebook and machine checks; it supervises daily operations.
