かさねぎについて

かさねぎは、大阪を拠点にする研究開発スタジオです。すでにあるデータに、AI で新しい次元を見出す。その一つの考えで、地球科学の研究、語学アプリ、AI エージェントのためのデータ API、完全自動のコンテンツ制作を手がけています。

開業は 2026 年 6 月ですが、仕事はその前から動いています。動画の制作システムは 1 月に作り始め、5 月に YouTube パートナープログラムの承認を受けました。データ API は 4 月に公開を始め、5 月には開発者向けのマーケットにも出品しています。

名前は、着物を一枚ずつ重ねて着る「重ね着」に由来します。地質学の知識に、ソフトウェアとデータと AI を重ねて、一つの価値に仕立てる。それが、かさねぎの仕事です。

01 · 研究

未知の隕石クレーターを探す

日本では、長野県の御池山が隕石クレーターとして知られています。山が険しく森に覆われた日本の国土には、まだ見つかっていないクレーターが残っていると考えられます。私たちは、日本全土をカバーする最新の赤色立体地図を、人の目ではなく AI で読み解き、国土全体から未知のクレーターを探しています。

AI にクレーターを見分けさせるため、世界の衝突構造を確認済みの 226 か所を含む 354 件の台帳にまとめ、そのうち 48 か所の地形を、公開されている 1 m 解像度のデータから日本の地図と同じ基準の赤色立体地図にそろえています。御池山では全国の赤色立体地図を色の差 1 段階以内で再現し、世界と日本の地形を同じ物差しで比べています。

日本全土の膨大な地形画像からクレーターの候補を拾い上げるには、高度な AI が欠かせません。拾い上げた候補は、鉱物鑑定士である代表が、現地で岩石を調べて確かめます。

02 · アプリ

漫画で学ぶ語学アプリ kasanegi

同じ漫画の日本語版と英語版を、スマホの中で頁ごとに重ねて読むアプリです。2 つの URL を入れると、一話全体が頁ごとに重なります。丸いレンズを動かすと、その部分だけもう一方の言語に切り替わります。好きな漫画が、そのまま語学の教材になります。

2 つの言語版の頁は、絵で照合して位置を合わせます。実際の漫画でも頁の対応を誤りなく取り、そのまま重ねて表示します。画像は端末の外に送りません。

Android アプリ、PC 版の円形ルーペ、ブラウザで試せるデモが動いています。

03 · データ API

日本の公的データを、AI がそのまま使える形に

国税庁、協会けんぽ、厚生労働省、内閣府、経済産業省の gBizINFO が公開している表や登録簿を、AI エージェントやソフトウェアが一度の呼び出しで使える API に作り替えています。2026 年 4 月に公開を始め、給与・法人・補助金の 3 製品を、kasanegi.com と開発者向けのマーケットで提供してきました。

中心となる JP Local Pack は、給与の控除、社会保険の等級、源泉所得税、消費税率、祝日、法人番号、インボイスの登録、Peppol の請求書の検証を、10 本の API で返します。源泉所得税は国税庁の月額表 1,856 マスをそのまま持ち、公式の値と全マスの一致を確かめています。円未満の端数の扱いも、74 万円を超える給与の計算式も、制度の決まりどおりです。2026 年 10 月から、この 10 本を無料で公開しています。

AI エージェントは、MCP サーバから 10 本を道具として見つけ、使い方と呼び出し先を受け取れます。

04 · システム

完全自動で収益を上げるコンテンツ制作システム

研究と開発には、AI の利用料だけでも毎月 400 ドル以上がかかります。その AI の利用枠の一部を使い、原稿の作成から編集、投稿までを AI が完全に自動で行うコンテンツ制作システムを、Claude Code で作りました。いまは、このシステムが生む収益で毎月の AI の利用料とそのほかの開発費をまかないながら、その規模を広げています。

AI で作られた動画の多くが品質や正確さの課題を抱えるなかで、このシステムは、試合の事実を公式のデータから機械的に取り込み、海外の掲示板や配信のコメントから反応を集めて選び、訳します。AI には原文を書かせず、選んだ反応の番号と訳だけを返させる作りにして、捏造を構造から防いでいます。

チャンネルは、ジャンルや言語の違うものがいくつも動いています。下はその中の、スポーツの 2 つです。

WITH CLAUDE

Claude とともに

かさねぎの事業は、どれも Claude を中心に組み立てています。

開発の中心

研究、アプリ、データ API、コンテンツ制作の設計・実装・検証を、Claude Code が中心になって進めています。研究のコミットは 292 件すべて、語学アプリは 273 件中 256 件、サッカーの制作システムは 529 件中 320 件、野球の制作システムは 435 件中 289 件が、Claude との共同作業です。

製品の中で

データ API は、Claude のような AI エージェントが使うための製品です。MCP サーバで 10 本の API を道具として公開しています。コンテンツ制作では、Claude API を本番の原稿の著者に使い、prompt caching と Message Batches で費用を抑えてきました。工程ごとに Claude と他のモデルを切り替えられる作りです。

記録を忘れない

Claude Code の上に、過去の会話と報告をすべて出所つきで引ける記憶の仕組みを作りました。発言のたびに関係する記録を差し込み、241 本の会話と 1,693 件の報告から、決めたことと試して捨てたことを取り違えないようにしています。
