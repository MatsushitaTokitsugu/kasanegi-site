かさねぎについて

すでにあるデータに、AI で新しい次元を見出す。かさねぎは、この一つの考えを貫く、大阪の研究開発スタジオです。

かさねぎは、地質の専門家である代表が率いる、AI エージェントのチームで動いています。代表が問いを立て、最後の判断を下します。研究の設計、一次資料との照合、データの処理と検証、ソフトウェアの実装は、Claude Code を中心とする AI エージェントを研究と開発の層として組み、担わせています。Claude Code の作業セッションは 6,600 を超えます。

この組み方で、研究も、ソフトウェアも、収益を上げる仕組みも、実際に動かしています。中心にあるのは、日本全土の地形から未知の隕石クレーターを探す研究です。好きな漫画を語学の教材に変えるアプリも、日本の公的データを AI エージェントの道具にするデータ API 群も、原稿から投稿までを AI が完全に自動で作る動画の制作システムも、同じ考えと同じ組み方から生まれた仕事です。動画の制作システムは実際に収益を上げ、研究と開発を支えています。

いま、かさねぎは、開業前から公開してきたデータ API、研究の処理、2 つの言語を重ね合わせる技術、動画の制作システム、そしてここに挙げていない多くの開発まで、そのすべてを、既存のデータ群から AI で新しい価値を生む一つの土台へ、大きく統合しています。その間も、データ API 群の一例として、JP Local Pack の 10 本を無料で開いています。

名前は、十二単のように衣を重ねて装う「重ね着」に由来します。重ねることで美しく、実用的になり、新しい価値が生まれる。データに AI を、知見に技術を重ね、進化を続ける。それが、かさねぎの仕事です。語学アプリにも、同じ名前を付けました。4 つの事業のコードは 45 万行を超え、コミットは 1,800 を超えます。

01 · 研究

日本全土から、未知の隕石クレーターを探す

最新の日本全土の赤色立体地図を土台に、世界の既知の衝突痕を機械学習で AI に学ばせ、国土全体の地形から未知の隕石クレーターを見分けさせる研究です。人が目で確かめ、手でデータを重ねてきたやり方では届かない速さと方法です。

日本で隕石クレーターと報告されているのは、長野県の御池山です。山が険しく森に覆われた国土には、見つかっていないクレーターが眠っていると考えられます。日本全土の画像からクレーターを見分けるには、機械学習による高度な AI が欠かせません。

人の手では到底届かない量の下ごしらえを、AI エージェントが担いました。AI が学ぶのは、世界の衝突構造です。67 の国と地域にわたる 354 件を一つの台帳にまとめ、そのうち 240 の構造に 2,011 本の論文を結び付けました。既知のクレーター 48 か所は、公開されている 1 m の標高データから赤色立体地図にしました。全国の赤色立体地図の計算も式と定数まで特定し、御池山で色の差 1 段階以内に再現しました。世界と日本の地形を、同じ物差しで比べられます。

地形に加えて、重力と空中磁気の全国の観測も、その質を一次資料と実データで見極めています。AI が挙げる候補は、鉱物鑑定士で地質の専門家である代表が、現地で岩石を調べて確かめます。同じ方法は、世界の地形へ、月面へ、そして古墳の発見へと広がります。

02 · アプリ

漫画で言語の壁を越える、語学アプリ kasanegi

同じ漫画の 2 つの言語版を、端末の中で頁ごとに重ねて読むアプリです。2 つの URL を入れると、一話全体がそろって重なります。丸いレンズを動かすと、そこだけもう一方の言語に変わります。好きな漫画が、そのまま語学の教材になります。

頁の対応は、並び順に頼らず、絵を照らし合わせて決め、位置を合わせて重ねます。実在の漫画の一話では 60 組、別の作品では 54 組の頁を、一つも取り違えずに対応させました。画像は端末の外に送りません。

絵で重ねるので、言語の組み合わせを選びません。屋号と同じ名前を持つ、かさねぎの考えをいちばん身近な形にしたアプリです。Android と PC で動き、ブラウザのデモでいますぐ確かめられます。PC 版のベータは高い評価をいただいており、有料での利用を希望する方は 20 人を超えます。

03 · データ API

日本の公的データを、AI エージェントがそのまま使える形に

国税庁、協会けんぽ、厚生労働省、内閣府、経済産業省の gBizINFO など、日本の公的機関が公開している表や登録簿を、AI エージェントやソフトウェアが一度の呼び出しで使える API に作り替える。かさねぎは開業前から、こうしたデータ API の群を開発し、kasanegi.com、開発者向けのマーケット、MCP で公開してきました。

いま、そのデータ API 群は、かさねぎのすべてを一つにする土台へ統合しています。その間も実物に触れていただけるよう、群の中の一つのアプローチとして、日本のバックオフィスの公的データを扱う JP Local Pack の 10 本を、登録なしで無料で開いています。

一例であっても、源泉所得税は国税庁の月額表の 1,856 マスをそのまま持ち、公式の表と全マス一致します。

外に開いていないデータ API 群も抱えています。企業の名寄せと企業情報の補強、有価証券報告書などの開示書類、補助金の検索と申請資格の判定など、公的データを AI エージェントの判断に直結させる API です。AI の資源が増えるほど、こうした群を外へ開いていきます。

データ API 群は、AI エージェントが自分で見つけて使えるように作っています。MCP サーバ、OpenAPI、llms.txt をそろえ、AI エージェントが使い方と呼び出し先を受け取って、そのまま使えます。

04 · システム

AI が完全に自動で作り、収益を上げる動画の制作システム

原稿の作成から編集、投稿までを AI が完全に自動で行う動画の制作システムを、Claude Code で開発しました。ジャンルも言語も違う 7 つのチャンネルを、このシステムが動かしています。

このシステムが作るのは、低質な AI 動画や作り話の混ざった動画ではなく、人が見る価値のある動画です。事実は決まった手順で出典と突き合わせ、AI には事実を作らせません。方針と最後の基準は、代表が持ちます。最新のチャンネルは、開設から 1 か月で累計 100 万回再生に達し、累計の総再生時間は 4.7 万時間です。

研究と開発には、最低限のサブスクリプションの固定費だけでも、毎月 400 ドル以上がかかります。動画は実際に収益を上げ、その費用と開発費をまかないながら、制作の規模を広げています。下に挙げる 2 つは、このシステムが動かすチャンネルの一例です。
